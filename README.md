# openshift-learning-lab
## Project Purpose

This repository tracks a hands-on platform engineering learning lab focused on building practical skills in containers, CI/CD, Kubernetes/OpenShift, GitOps, and artifact management. All configurations, pipelines, and manifests are stored in GitHub using free or near-zero-cost services designed to minimize local resource usage and remain easy to resume after long periods of inactivity.
